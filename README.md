# 💡 Interactive Programming Quiz App

A clean, responsive web application built with vanilla HTML, CSS, and JavaScript that tests users on programming fundamentals. The app dynamically selects a fresh set of questions for every attempt and features detailed post-quiz feedback.
## ✨ Features
* **Randomized Question Pool:** Selects 10 unique questions randomly from a comprehensive 100-question database on each run.
* * **Detailed Answer Review:** Provides a full item-by-item breakdown showing correct answers and highlighted mistakes.
  * ## 🛠️ Tech Stack
* **HTML5** - Structured game layout and semantic elements.
* **CSS3** - Custom styling, Flexbox layouts, dark theme, and smooth UI transitions.
* **JavaScript (ES6+)** - Dynamic DOM manipulation, array shuffling algorithms, score calculation, and review logic.
